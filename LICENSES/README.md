# Licence texts

| File | Licence | Used here for |
|---|---|---|
| `BSD-3-Clause.txt` | BSD-3-Clause | the owner's files other than Markdown |
| `CC-BY-4.0.txt` | CC BY 4.0 | the owner's Markdown files |
| `CC-BY-3.0.txt` | CC BY 3.0 Unported | the die-derived 8080 model (in `retroICs`) |
| `LicenseRef-Tselikov-BSD.txt` | Dmitry Tselikov's BSD-style licence | the 8257 and 8275 models (in `retroICs`); the licence named for the ROM images (`machines/rk86/roms/PROVENANCE.md`) |

- The four files are byte-identical copies of `LICENSES/` of `retroICs` (the submodule
  `lib/retroICs`), which records the source of each text; `tools/tests/test_licences.py` checks
  that they still are copies.
- The owner's copyright line is in `../LICENSE`; the attribution line is in `../NOTICE`.
